## Estrutura e publicação

Cada projeto da Vercel continua com seu domínio e suas configurações. A pasta indicada deve ser definida como **Root Directory** do projeto correspondente ao conectar este repositório. O código de cada demo foi copiado sem alterações de sua versão de origem, para facilitar a conferência e o retorno à configuração anterior.

## Sobre os projetos

Estas páginas demonstram direção visual, interfaces responsivas e interações para diferentes segmentos. Sistemas com autenticação, banco de dados ou integrações próprias ficam em repositórios separados.
